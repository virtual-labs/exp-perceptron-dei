### About the Experiment 

This experiment provides an interactive simulation of the Perceptron, a fundamental building block of neural networks and deep learning. Students will explore how a perceptron learns to classify data by adjusting weights based on training examples. Through hands-on simulation, learners will understand the mathematical principles behind single-layer neural networks and gain insights into machine learning fundamentals. This virtual lab makes theoretical concepts concrete through interactive visualization and practical experimentation.
